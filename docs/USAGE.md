# 使用指南

本文覆盖风宝音乐下载器的日常使用方式。构建与开发请见 [BUILD.md](BUILD.md)，接口细节见 [API.md](API.md)。

---

## 1. 界面总览

左侧导航包含四个页面：

| 页面 | 作用 |
| --- | --- |
| 搜索 | 单源 / 全网检索歌曲，单曲或批量下载，试听 |
| 批量导入 | 粘贴网易云歌单链接或 ID，整单解析导入 |
| 下载管理 | 查看进度、速度、取消任务、定位文件 |
| 设置 | 保存路径、命名规则、音质、标签、音源脚本 |

底部迷你播放器支持播放 / 暂停、进度拖拽、音量调节和关闭。

---

## 2. 搜索歌曲

1. 在顶部输入框输入歌名、歌手或专辑，回车或点「全网搜索」；
2. 用平台按钮切换：**全网聚合 / QQ音乐 / 酷狗音乐 / 酷我音乐 / 网易云**；
3. 表格中的音质标签（`FLAC` / `320K` / `128K`）可直接点击，按该音质解析下载；
4. 点击封面或「试听」按钮可试听 128K 音源。

> 全网聚合会并发请求各平台并按「歌名 + 歌手」去重，结果数量取决于各平台返回。

---

## 3. 批量导入歌单

进入「批量导入」，支持：

- 网易云歌单分享链接，例如 `https://music.163.com/playlist?id=3778678`；
- 纯歌单数字 ID，例如 `3778678`；
- 页面内置的几个热门榜单快捷入口。

解析成功后可全选或勾选部分歌曲，按当前「首选音质」批量加入下载队列。

---

## 4. 下载与文件

### 下载流程

1. 解析音源直链（后端 `/api/resolve`，自动跨源匹配并过滤 VIP 试听片段）；
2. 写入 `.downloading` 临时文件；
3. 下载完成后原子重命名为最终文件；
4. 写入 ID3v2.3 / FLAC 标签与封面。

### 默认输出

- 格式：MP3（首选 320K，失败时降级 128K）或 FLAC；
- 文件名：默认 `{singer} - {name}`，可在设置中切换；
- 元数据：标题、歌手、专辑、封面、歌词（详见下一节）。

### 下载管理

- 支持 1~5 并发，实时显示进度、速度、已下载 / 总大小；
- 「取消」会终止任务并删除临时文件；
- 完成后可点「定位文件」在资源管理器中选中文件；
- 「清除已完成」只清空列表，不删除文件。

## 5. 封面与歌词

### MP3（ID3v2.3）

| 帧 | 内容 |
| --- | --- |
| `TIT2` / `TPE1` / `TALB` | 标题 / 歌手 / 专辑 |
| `USLT` | 非同步 LRC 歌词（UTF-16） |
| `SYLT` | 同步滚动歌词（毫秒时间戳） |
| `APIC` | 前置封面，优先 500×500 JPEG/PNG |

- 标签版本固定为 **ID3v2.3**，因为 Windows 资源管理器、WMP、椒盐音乐以及大量车载/国产播放器**不识别 ID3v2.4 的封面帧**；
- 写入前会校验图片文件头，避免把错误页当成封面；
- 已有 ID3v2 标签会被替换，音频流保持不变。

### FLAC

- Vorbis Comment：`TITLE` / `ARTIST` / `ALBUM` / `LYRICS` / `UNSYNCEDLYRICS`；
- Picture Block：前置封面。

### 独立 `.lrc` 文件

默认**不生成**。若播放器只认同名 `.lrc`，可在设置中开启「额外另存 .lrc 歌词文件」，此时会在歌曲同目录额外生成一个同名 `.lrc`。

### 播放器看不到歌词？

- 确认播放器支持 ID3v2 歌词帧（foobar2000、Poweramp、海贝音乐等）；
- 老式车载播放器建议开启 `.lrc` 外挂；
- 若封面不显示，请确认下载的是 v1.3.1 及以上版本，并重新下载歌曲（旧文件不会自动修复）。

## 6. 设置项

| 设置 | 说明 |
| --- | --- |
| 保存路径 | 默认 `%USERPROFILE%\Music\AnHeMusic`，可调起原生目录选择器修改 |
| 文件命名 | `{singer} - {name}` / `{name} - {singer}` / `{name}` |
| 首选音质 | `FLAC 无损优先` / `320Kbps 高品` / `128Kbps 标准`，默认 320K |
| 智能自动降级 | 目标音质不可用时自动降级，避免下载失败 |
| 嵌入高清封面 | 写入 `APIC` / FLAC Picture |
| 嵌入歌词 | 写入 `USLT` + `SYLT` / Vorbis Comment |
| 额外另存 .lrc | 默认关闭 |
| 最大并发下载数 | 1~5 |
| 音源管理 | 连通性测试、更换音源脚本、恢复内置音源 |

> 设置目前只在本次运行内生效；重启后下载路径会回到程序默认目录。

## 7. 洛雪音源脚本

### 协议约定

脚本需在 `globalThis.lx` 环境下运行：

- 通过 `lx.on('request', handler)` 注册解析器；
- 平台标识通常为 `kw` / `kg` / `wy` / `tx` / `mg`；
- 请求参数包含 `source`、`action`（`musicUrl`）、`info.type`（音质）与 `musicInfo`。

### 上传与生效

1. 设置页点击「更换音源脚本」，选择 `.js` 文件；
2. 前端先在内存中执行脚本，校验是否注册了 `request` 处理器；
3. 校验通过后 `POST /api/source-script` 保存为程序目录下的 `custom-source.js`；
4. 重新加载并刷新音源状态，提示中会显示脚本真实的 `@name` 与版本；
5. 下次启动优先加载该脚本。

### 恢复

- 点击「恢复内置音源」或调用 `DELETE /api/source-script`；
- 会删除 `custom-source.js`，回退到程序目录中的内置脚本（若存在）。

### 安全提示

音源脚本是可直接执行的 JavaScript，请只加载可信来源的脚本。仓库出于版权考虑不附带任何第三方音源脚本。

---

## 8. 数据与隐私

- 所有请求由本机发起，服务仅监听 `127.0.0.1`；
- 不上传歌曲、搜索词或下载记录到任何自建服务器；
- 下载文件保存在你选择的本地目录。
