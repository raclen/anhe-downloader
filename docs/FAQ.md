# 常见问题

## 下载与音源

### 为什么 VIP 歌曲下载不了？

各音乐平台的免费接口对 VIP / 付费曲目通常只返回十几秒的试听片段。解析器会用 `Range` 请求探测音频总大小，小于 900KB 视为占位片段并拒绝，界面提示「暂无可下载的完整音源」。

这是版权限制，不是程序 bug。可以尝试：

- 换一个非 VIP 版本（Live、翻唱、其他歌手）；
- 更新音源脚本（见下文）；
- 使用自己拥有权限的音源服务。

### 为什么 QQ 音乐搜得到，但下载失败？

QQ 官方接口对免费曲目只提供 `m4a`，320K MP3 需要 VIP 登录凭证。程序会尝试用歌名 + 歌手跨源匹配酷我 / 酷狗 / 网易云的 MP3；若都匹配不到，会提示换源。跨源匹配会严格校验歌手，避免下成别人的翻唱。

### 提示「解析接口不可用」怎么办？

- 检查网络能否访问对应平台；
- 平台接口可能临时变更，等待修复或更换音源脚本；
- 尝试在设置中使用「连通性测试」确认后端解析是否正常。

### 下载到一半失败了？

- 任务会停在 `error` 状态并显示原因；
- 目标目录会保留 `.downloading` 临时文件，重新下载会覆盖；
- 若目标文件被播放器占用，关闭播放器后重试。

## 封面与歌词

### 为什么播放器看不到封面？

1. 确认使用的是 **v1.3.1 及以上**版本（旧版本写的是 ID3v2.4，Windows / WMP / 椒盐音乐等只认 ID3v2.3）；
2. 旧版本下载的文件不会自动修复，需要**重新下载**；
3. 确认播放器支持读取 ID3v2.3 `APIC`，可用 foobar2000、Poweramp、海贝音乐等验证；
4. 若仍不行，可用 `ffprobe` 检查文件是否包含 `mjpeg` 封面流。

### 为什么只有一个 MP3，没有 .lrc？

这是默认行为：歌词已经以 `USLT` + `SYLT` 内嵌进 MP3。若播放器需要外挂歌词，请在设置中开启「额外另存 .lrc 歌词文件」。

### 歌词能滚动显示吗？

会写入 `SYLT` 同步歌词帧（毫秒时间戳），支持该帧的播放器可按时间轴滚动；不支持的播放器会退化为显示 `USLT` 文本或完全不显示。

### 封面为什么是 500×500？

程序会优先取平台的高清封面（酷我 `120/240/300` 自动换 `500`），并校验图片文件头，避免把错误页写进标签。

## 音源脚本

### 为什么仓库里没有音源脚本？

出于版权与授权考虑，仓库不附带任何第三方音源脚本（`长青*.js`、`custom-source.js` 等均被忽略）。程序仍可使用内置的跨源解析链下载免费曲目。

### 更换音源后重启又变回去了？

请使用设置页的「更换音源脚本」上传。脚本会保存为程序目录的 `custom-source.js` 并在启动时优先加载；直接替换内置脚本文件不会被持久化。

### 上传脚本提示「脚本无效」？

脚本必须在执行后同步注册 `lx.on('request', handler)`，否则会被判定无效。请检查：

- 脚本是否为洛雪自定义音源格式；
- 脚本是否依赖浏览器之外的环境；
- 浏览器控制台是否有语法错误。

### 如何恢复内置音源？

设置页点击「恢复内置音源」，或调用 `DELETE /api/source-script`。程序会删除 `custom-source.js` 并回退到程序目录中的内置脚本（若存在）。

## 安装与运行

### 双击没反应 / 窗口空白？

- Windows 10/11 一般自带 WebView2；若精简系统缺失，请安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；
- 检查杀毒软件是否拦截了本地端口或 exe；
- 可用 `anhe-downloader.exe -headless -port 45678` 启动后浏览器访问，查看是否有报错。

### 45678 端口被占用怎么办？

程序会自动尝试随机端口。也可手动指定：

```bash
anhe-downloader.exe -headless -port 46000
```

### 设置为什么重启后恢复默认？

当前版本的设置只保存在运行时；下载路径会重新读取默认目录。若需要持久化配置，可在后续版本中加入本地配置文件。

### 支持 macOS / Linux 吗？

桌面窗口依赖 Windows WebView2。其他系统可尝试 `-headless` 模式自行构建，但未做完整测试。

## 数据与安全

### 会上传我的搜索或下载记录吗？

不会。所有请求由本机发起，服务只监听 `127.0.0.1`，不使用任何自建中转服务器。

### 音源脚本安全吗？

音源脚本是可直接执行的 JavaScript，能力等同于在应用内运行任意代码。请只加载可信来源的脚本。
